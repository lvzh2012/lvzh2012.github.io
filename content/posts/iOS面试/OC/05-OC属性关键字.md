# 第五章：OC 属性关键字（@property）

## 5.1 总览

`@property` 由编译器 **自动生成 getter/setter**，声明 **内存管理 + 原子性 + 读写权限** 等语义。

```objc
@property (nonatomic, strong, readonly) NSString *name;
//        └─属性特性─┘  └─读写─┘
```

| 类别 | 可选关键字 | 默认（ARC） |
|------|------------|-------------|
| **内存管理** | `strong` `weak` `copy` `assign` `unsafe_unretained` | `strong`（对象） |
| **原子性** | `atomic` `nonatomic` | `atomic`（工程习惯写 nonatomic） |
| **读写** | `readwrite` `readonly` | `readwrite` |
| **其他** | `nullable` / `nonnull`、getter/setter 重命名 | — |

---

## 5.2 内存管理修饰符（必背）

### 对照表

| 关键字 | ARC 行为 | 适用类型 | 典型场景 |
|--------|----------|----------|----------|
| **strong** | 强引用，+1 | Objective-C 对象 | 默认；subview、model |
| **weak** | 弱引用，不 +1；释放后 **自动置 nil** | OC 对象 | delegate、打破循环引用 |
| **copy** | 拷贝一份再 strong 持有 | 对象（尤其可变类） | `NSString`、Block |
| **assign** | 不 +1，不管理生命周期 | 基本类型、C 结构体 | `NSInteger`、`BOOL` |
| **unsafe_unretained** | 同 assign，释放后 **不置 nil** | OC 对象（不推荐） | 极少用 |

> MRC 还有 **retain**（≈ strong）。ARC 下对象用 **strong / weak / copy**，不要用 assign 持对象。

### strong

```objc
@property (nonatomic, strong) UIView *container;
```

- **语义**：旧值引用计数 −1，新值 +1
- **ARC**（`@property strong` 编译器生成）：底层 `objc_storeStrong` 顺序是 **先 retain 新值 → 赋值 → 再 release 旧值**（防 `self.x = _x` 自赋值时对象提前释放）
- **MRC 手写 setter**（需先 `if (_x != x)` 判断）：**先 release 旧值 → 再 retain 新值**

```objc
// MRC 常见模板
- (void)setContainer:(UIView *)container {
    if (_container != container) {
        [_container release];
        _container = [container retain];
    }
}
```

- 两个 strong 互持 → **循环引用**（一侧改 weak）

### weak

```objc
@property (nonatomic, weak) id<MyDelegate> delegate;
```

- 不增加引用计数；dealloc 后 **自动 nil**（Side Table，见 [第六章 §6.1](/posts/%E7%AC%AC%E5%85%AD%E7%AB%A0%E6%89%A9%E5%B1%95%E5%85%AB%E8%82%A1%E5%86%85%E5%AD%98-runloop-%E5%85%B3%E8%81%94%E7%9F%A5%E8%AF%86%E7%82%B9.html)）
- **delegate 几乎总是 weak**

### copy —— 为什么 NSString / Block 用 copy？

```objc
@property (nonatomic, copy) NSString *title;
```

**strong 的问题**：

```objc
@property (nonatomic, strong) NSMutableString *title;

NSMutableString *m = [NSMutableString stringWithString:@"hi"];
obj.title = m;
[m appendString:@"!!!"];   // 外部改了，obj.title 也变 ❌
```

**copy setter 等价逻辑**：

```objc
- (void)setTitle:(NSString *)title {
    _title = [title copy];   // 独立副本，与外部 mutable 脱钩
}
```

| 类型 | 推荐 | 原因 |
|------|------|------|
| `NSString` / `NSArray` / `NSDictionary` / `NSSet` | **copy** | 防 mutable 子类被外部改 |
| `NSMutable*` | **strong** | 需要可变 |
| **Block** | **copy** | 栈 Block 到堆；见 [第三章 Block](/posts/%E7%AC%AC%E4%B8%89%E7%AB%A0block-%E9%9D%A2%E8%AF%95%E5%85%AB%E8%82%A1.html) |

### 浅拷贝 vs 深拷贝（必考）

| 概念 | 含义 |
|------|------|
| **浅拷贝** | 新建容器/对象外壳，**内部元素仍指向同一批对象**（共享引用） |
| **深拷贝** | 递归复制，**容器 + 内部可变元素** 都独立（至少「一层深」） |

Foundation 里 **`copy` 不一定是深拷贝**，取决于类对 `<NSCopying>` 的实现。

#### 各类 `copy` 行为对照

| 类型 | `[obj copy]` | `[obj mutableCopy]` | 说明 |
|------|--------------|---------------------|------|
| `NSString` / 不可变字符串 | **可能返回 self**（优化） | 新 `NSMutableString` | `@property copy` 防外部传入 `NSMutableString` |
| `NSMutableString` | 新 **不可变** 副本 | 新 **可变** 副本 | setter 里 `copy` 与外部 mutable 脱钩 |
| `NSArray` | 新数组，**元素同一引用** | 新可变数组，**元素同一引用** | 浅拷贝 |
| `NSMutableArray` | 新不可变数组，元素共享 | 新可变数组，元素共享 | 浅拷贝 |
| `NSDictionary` / `NSSet` | 同 NSArray | 同 NSArray | 浅拷贝 |
| `NSArray` **元素也是容器** | 只拷外层 | `mutableCopy` **一层深**：外层 + 每个元素各 `mutableCopy` 一次 | 嵌套仍可能共享 |
| 自定义 Model | 看 `copyWithZone:` 实现 | 看 `mutableCopy` 实现 | 面试常问「你怎么实现深拷贝」 |

#### Demo 1：`@property copy` 防 mutable 篡改（属性层「浅拷贝」）

```objc
@property (nonatomic, copy) NSString *title;

NSMutableString *m = [NSMutableString stringWithString:@"hi"];
obj.title = m;              // setter 内部 [m copy] → 不可变副本
[m appendString:@"!!!"];    // m 变了
NSLog(@"%@", obj.title);    // hi  ✅ 属性不受影响
```

#### Demo 2：容器 `copy` 只浅拷贝元素

```objc
NSMutableArray *inner = [NSMutableArray arrayWithObject:@(1)];
NSMutableArray *outer = [NSMutableArray arrayWithObject:inner];

NSArray *copied = [outer copy];           // 新 outer，元素指针相同
NSMutableArray *inner2 = copied[0];
[inner2 addObject:@(2)];

NSLog(@"%@", outer[0]);   // (1, 2)  ❌ 原数组里的 inner 也被改了
NSLog(@"%@", copied[0]);  // (1, 2)  同一对象
```

#### Demo 3：`mutableCopy` 一层深拷贝（阿里常考）

```objc
NSMutableArray *inner = [NSMutableArray arrayWithObject:@(1)];
NSMutableArray *outer = [NSMutableArray arrayWithObject:inner];

NSMutableArray *deepOneLevel = [outer mutableCopy];
// 等价于：新 outer + 对每个元素 send mutableCopy
// inner 被 mutableCopy 成新的 NSMutableArray，与原来 inner 脱钩

[(NSMutableArray *)deepOneLevel[0] addObject:@(99)];
NSLog(@"%@", outer[0]);        // (1)     ✅ 不受影响
NSLog(@"%@", deepOneLevel[0]); // (1, 99)
```

#### Demo 4：真正「全深」要自己写

系统没有通用的「无限递归深拷贝」；嵌套层级多时要手写：

```objc
- (NSArray *)deepCopyArray:(NSArray *)array {
    NSMutableArray *result = [NSMutableArray arrayWithCapacity:array.count];
    for (id obj in array) {
        if ([obj conformsToProtocol:@protocol(NSMutableCopying)]) {
            [result addObject:[obj mutableCopy]];
        } else if ([obj conformsToProtocol:@protocol(NSCopying)]) {
            [result addObject:[obj copy]];
        } else {
            [result addObject:obj];  // 基本类型 / 不可拷贝对象只能共享
        }
    }
    return [result copy];
}
```

#### 与 `@property` 关键字的关系

| 修饰 | setter 行为 | 拷贝深度 |
|------|-------------|----------|
| **strong** | retain 指针 | 无拷贝，共享同一对象 |
| **copy** | `[newValue copy]` | 见上表：字符串常为新不可变副本；容器多为**浅拷贝** |
| 需要深拷贝 | 不要指望 `copy` 关键字 alone | 自定义 setter 或 Model 实现 `NSCopying` |

```objc
// ❌ 以为 copy 属性会自动深拷贝嵌套数组
@property (nonatomic, copy) NSArray *items;

// ✅ 业务要隔离时：immutable 对外 + 赋值时用深拷贝方法
- (void)setItems:(NSArray *)items {
    _items = [self deepCopyArray:items];
}
```

**面试一句话**：

> `@property copy` 保证 **setter 时** 与传入对象脱钩；对 **容器** 仍是浅拷贝，元素共享。要一层深用 **`mutableCopy`** 或 **`arrayByAddingObjectsFromArray:` + 元素逐个 copy**；多层嵌套需 **手写 `copyWithZone:`**。

### assign

```objc
@property (nonatomic, assign) NSInteger count;
@property (nonatomic, assign) BOOL enabled;
```

- **仅值类型**；对象用 assign → 野指针，ARC 下编译警告

### unsafe_unretained vs weak

| | weak | unsafe_unretained |
|--|------|-------------------|
| 释放后 | **nil** | **野指针** crash |
| 开销 | Side Table | 无 |
| 使用 | delegate | 几乎不用 |

## 5.3 atomic vs nonatomic

| | atomic | nonatomic |
|--|--------|-----------|
| accessor | getter/setter **加锁** | 无锁，更快 |
| 线程安全 | 仅 **单次赋值** 原子 | 不保证 |
| 实践 | 语法默认 atomic | **UIKit 全写 nonatomic** |

```objc
@property (atomic, strong) NSMutableArray *list;
// atomic 不能保证：
// self.list = [self.list arrayByAddingObject:x];  // 读-改-写仍不安全
```

> 业务线程安全靠锁 / 串行队列。详见 [第四章 §4.7](/posts/%E7%AC%AC%E5%9B%9B%E7%AB%A0%E5%A4%9A%E7%BA%BF%E7%A8%8B%E9%9D%A2%E8%AF%95%E5%85%AB%E8%82%A1.html)。

## 5.4 readwrite vs readonly

```objc
// .h 对外只读
@property (nonatomic, strong, readonly) NSString *userId;

// .m
@interface MyClass ()
@property (nonatomic, strong, readwrite) NSString *userId;
@end
```

- **readonly**：只生成 getter；`.m` 内通过 `_ivar` 或 readwrite 重声明赋值

## 5.5 getter / setter 自定义

```objc
@property (nonatomic, getter=isEnabled) BOOL enabled;
@property (nonatomic, copy, setter=applyName:) NSString *name;
```

- 默认 getter = 属性名，setter = `setXxx:`
- BOOL 常用 `getter=isXxx`

## 5.6 选型速查（面试直接背）

| 场景 | 推荐 |
|------|------|
| delegate | `(nonatomic, weak)` |
| NSString / URL 字符串 | `(nonatomic, copy)` |
| Block 属性 | `(nonatomic, copy)` |
| subview / 子 VC | `(nonatomic, strong)` |
| int / enum / BOOL | `(nonatomic, assign)` |
| 对外只读 | `.h readonly` + `.m readwrite` |
| 一般 UI | **nonatomic** |
| 嵌套数组要隔离 | 手写深拷贝，别只信 `copy` 属性 |

### 错误示例

```objc
@property (nonatomic, strong) NSString *name;              // ❌ 应用 copy
@property (nonatomic, strong) id<Delegate> delegate;       // ❌ 应用 weak
@property (nonatomic, assign) NSObject *obj;                 // ❌ 野指针
```

## 5.7 @property · @synthesize · @dynamic

| | 作用 |
|--|------|
| `@property` | 声明 + 编译器生成 accessor |
| `@synthesize` | 指定 ivar（现代默认 `_propName`，很少写） |
| `@dynamic` | 不自动生成；Runtime / 子类 / Core Data 提供实现 |

**Category 里 @property**：不能加 ivar，用 Associated Objects 或手写 accessor → [第八章 Q4](/posts/%E7%AC%AC%E5%85%AB%E7%AB%A0%E7%BB%BC%E5%90%88%E4%B8%B2%E8%81%94%E9%A2%98%E9%AB%98%E9%A2%91.html)。

## 5.8 高频面试 Q&A

### Q1：copy 和 strong 区别？

- **strong**：共享同一对象，+1
- **copy**：setter 里 `[newValue copy]`，**独立副本**（字符串/Block 防 mutable；容器多为浅拷贝）

### Q1b：浅拷贝和深拷贝区别？`copy` 是深拷贝吗？

- **不一定**。`NSString` 的 `copy` 常为新不可变副本；**`NSArray`/`NSDictionary` 的 `copy` 是浅拷贝**（新容器，元素同引用）
- **`mutableCopy`** 对容器是 **一层深拷贝**（外层 + 每个元素 `mutableCopy` 一次）
- **全深拷贝**需 Model 自己实现 `copyWithZone:` 或递归拷贝

### Q2：Block 属性为何 copy？

MRC 栈 Block 必须 copy；ARC 下 copy 语义仍正确。见 [第三章 §3.6](/posts/%E7%AC%AC%E4%B8%89%E7%AB%A0block-%E9%9D%A2%E8%AF%95%E5%85%AB%E8%82%A1.html)。

### Q3：atomic 线程安全吗？

否。只保证单次 getter/setter，不保证读-改-写复合操作。

### Q4：assign 能用于对象吗？

ARC 下不行，应 strong/weak/copy。
