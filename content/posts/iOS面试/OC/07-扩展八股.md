## 7.1 weak 原理

- `__weak` 引用登记在 **Side Table** 的 weak 哈希表
- 对象 dealloc 时遍历 weak 表，关联指针 **全部置 nil**
- 64 位 **non-pointer isa** 中 `weakly_referenced` 标志位；详见 [第一章 §1.2](/posts/%E7%AC%AC%E4%B8%80%E7%AB%A0isa-%E4%B8%8E-superclass.html)

**为何 weak 不能塞进 isa？** extra_rc 只存强引用计数，weak 表必须在 Side Table。

### 存储结构

```
SideTables()（全局 64 个 SideTable，按对象地址哈希取模 + 各持一把锁）
 ├─ slock            自旋锁（spinlock_t）
 ├─ refcnts          强引用计数表（对象地址 → 计数）
 └─ weak_table       弱引用表
      ├─ weak_entries[]          弱条目数组（哈希表，开放寻址 = 线性探测）
      ├─ num_entries             条目数
      ├─ mask                   容量 - 1（取模用）
      └─ max_hash_displacement  最大探测位移，超阈值触发扩容

weak_entry_t（被 weak 引用的每个对象对应一条）
 ├─ referent          被引用对象指针（外层 key）
 └─ referrers[]       指向该对象的「弱指针地址」数组
      ├─ 内联 4 个（WEAK_INLINE_COUNT = 4）→ 存进结构体内部，不额外分配
      └─ 超过 4 个 → 转 out-of-line 数组（同样按地址哈希 + 线性探测）
```

### Key-Value 形式（两层哈希）

| 层 | key | value |
|----|-----|-------|
| SideTables 索引 | 对象地址 | SideTable（加锁粒度） |
| weak_table 外层 | **referent**：被引用对象（`DisguisedPtr` 伪装指针） | **weak_entry_t**：该对象的所有弱引用条目 |
| referrers 内层 | 弱指针自身的地址 | 被引用对象 |

- 同一对象有 N 个 `__weak` 引用 → 外层只占 **一条** `weak_entry_t`，内层 referrers 存 **N 个弱指针地址**
- 增删改查都是「对象地址 / 弱指针地址」哈希 → 均摊 **O(1)**
- 对象 dealloc → 外层按 referent 找到 entry → 遍历 referrers 把每个弱指针 **置 nil** → 再摘除 entry
- `DisguisedPtr` 是把指针地址做位伪装（去掉低 3 位干扰），避免与真实指针混淆、优化内存布局

## 7.2 RunLoop · AutoreleasePool

> **RunLoop 源码深度内容已独立为第八章，见 [08-RunLoop源码面试题.md](/posts/%E7%AC%AC%E5%85%AB%E7%AB%A0runloop-%E6%BA%90%E7%A0%81%E9%9D%A2%E8%AF%95%E9%A2%98%E5%9F%BA%E4%BA%8E-cfrunloop.c.html)**。  
> 本章仅保留核心对照。

| 主题 | 要点 |
|------|------|
| **RunLoop** | 触摸、Timer、Source 由 RunLoop 驱动；**主线程默认开启**；子线程需 `run` |
| **AutoreleasePool** | `AutoreleasePoolPage` 双向链表；RunLoop **休眠/唤醒** 时 drain |
| **与线程** | 每条线程最多一个 RunLoop（存在线程 → RunLoop 一一对应）；主线程 RunLoop 在 `main` 里自动 run |
| **Source0 vs Source1** | Source0 应用层事件（触摸），需手动唤醒；Source1 基于 mach_port，自动唤醒 |
| **休眠原理** | `mach_msg` 系统调用进入内核态等待，零 CPU 占用 |
| **源码结构** | `__CFRunLoop` 含 `_pthread`、`_modes`、`_commonModes`、`_currentMode` 等 |
| **完整循环** | Entry → BeforeTimers → BeforeSources → Source0 → DoBlocks → BeforeWaiting → mach_msg → AfterWaiting → 处理事件 → 循环 |

## 7.4 高频面试 Q&A

### Q1：AutoreleasePool 什么时候释放？

RunLoop 每轮循环**休眠前**（BeforeWaiting）pop + push 一次；退出时最终 pop。线程退出时也 drain。或手动 `@autoreleasepool {}` 作用域结束。  
> 更多 RunLoop 源码题见 [第八章 Q&A](/posts/%E7%AC%AC%E5%85%AB%E7%AB%A0runloop-%E6%BA%90%E7%A0%81%E9%9D%A2%E8%AF%95%E9%A2%98%E5%9F%BA%E4%BA%8E-cfrunloop.c.html#89-基于源码的高频面试-qa)。

### Q2：weak 和 assign 区别？

见 [第六章 §6.2](/posts/%E7%AC%AC%E5%85%AD%E7%AB%A0oc-%E5%B1%9E%E6%80%A7%E5%85%B3%E9%94%AE%E5%AD%97@property.html)：weak 释放后 nil；assign 不置 nil。
