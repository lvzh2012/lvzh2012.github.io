# AI / 大模型面试题（2025～2026 热门）

> 2026 年大厂面试已从「会不会调 API」转向 **AI 应用落地**：RAG、Agent、MCP、评测闭环、生产架构。  
> **iOS 岗** increasingly 会问：App 如何接 LLM、流式 UI、端侧推理、隐私与成本。  
> 参考整理：[JavaGuide AI 面试指南](https://javaguide.cn/ai/interview-questions/ai-interview-guide.html) · [小林 AI 面试笔记](https://xiaolincoding.com/project/xiaolinnote.html)

## 一、大模型基础（必考 12 题）

| # | 题目 | 频率 | 要点（30 秒版） |
|---|------|------|----------------|
| 1 | Token 是什么？和字/词什么关系？ | ⭐⭐⭐⭐⭐ | 模型最小文本单元；中文常 1～2 字/token；计费、上下文上限都按 token |
| 2 | 上下文窗口（Context Window）是什么？超了怎么办？ | ⭐⭐⭐⭐⭐ | 一次能喂给模型的最大 token；超出需截断、摘要、RAG 外挂知识 |
| 3 | Temperature / Top-p 区别？ | ⭐⭐⭐⭐ | Temperature 控制随机性；Top-p 核采样限制候选集；创意高温度，事实低温度 |
| 4 | 什么是幻觉（Hallucination）？怎么缓解？ | ⭐⭐⭐⭐⭐ | 模型编造事实；RAG  grounding、低温度、引用来源、评测集、拒答策略 |
| 5 | Prompt 和 System Prompt 区别？ | ⭐⭐⭐⭐ | System 定角色/约束；User 是用户输入；Few-shot 示例放 User/Assistant |
| 6 | 流式输出（Streaming / SSE）原理？ | ⭐⭐⭐⭐ | 服务端逐 chunk 返回；iOS 用 URLSession 流式读或 WebSocket；UI 逐字渲染（原理见 [Common/08 §8.9](/posts/%E7%AC%AC%E5%85%AB%E7%AB%A0%E7%BD%91%E7%BB%9C%E4%B8%8E-http%E5%A4%A7%E5%8E%82%E9%AB%98%E9%A2%91-%E5%8E%9F%E7%90%86%E8%AF%A6%E8%A7%A3.html)） |
| 7 | 结构化输出（JSON Mode / Function Calling）解决什么？ | ⭐⭐⭐⭐ | 让输出可解析；Function Calling 让模型选工具+填参数，非真正执行 |
| 8 | GPT / Claude / 开源模型（Llama/Qwen）选型差异？ | ⭐⭐⭐ | 能力、成本、延迟、私有化、合规；生产常多模型路由+降级 |
| 9 | Embedding 是什么？和 LLM 什么关系？ | ⭐⭐⭐⭐⭐ | 文本→稠密向量；语义相似度检索；RAG 召回核心，不生成文本 |
| 10 | 微调（Fine-tune）vs RAG 怎么选？ | ⭐⭐⭐⭐ | RAG 改知识不改权重、可热更新；微调改行为/风格、成本高；常组合 |
| 11 | LoRA / PEFT 是什么？ | ⭐⭐⭐ | 低秩适配，只训少量参数；全量微调太贵时的工程方案 |
| 12 | RLHF / DPO 一句话？ | ⭐⭐⭐ | 人类偏好对齐；DPO 无需单独 Reward Model，训练更简单 |

## 二、RAG（检索增强生成 · 20 题）

| # | 题目 | 频率 | 要点 |
|---|------|------|------|
| 13 | RAG 完整流程？ | ⭐⭐⭐⭐⭐ | 文档切分 → Embedding → 向量库 → Query 向量化 → 召回 →（可选 Rerank）→ 拼 Prompt → LLM 生成 |
| 14 | RAG 和 Fine-tune 区别？ | ⭐⭐⭐⭐ | 见 #10 |
| 15 | Chunk 怎么切？太大太小有什么问题？ | ⭐⭐⭐⭐ | 按段落/固定长度+重叠；太大噪声多、太小丢上下文 |
| 16 | 向量数据库有哪些？选型看什么？ | ⭐⭐⭐⭐ | Milvus、Pinecone、pgvector、Faiss；看规模、过滤、混合检索、运维 |
| 17 | 召回率低怎么排查？ | ⭐⭐⭐⭐⭐ | **评估→Chunk→Embedding→Query 改写→Hybrid→Rerank→Prompt** 逐层查 |
| 18 | Hybrid Search 是什么？ | ⭐⭐⭐⭐ | 向量检索 + BM25 关键词；专有名词、ID 类 query 向量易 miss |
| 19 | Query Rewrite / HyDE 解决什么？ | ⭐⭐⭐ | 用户口语化 query 改写为检索友好；HyDE 用 LLM 先生假答案再检索 |
| 20 | Rerank 为什么需要？ | ⭐⭐⭐⭐ | 向量召回 TopK 粗排；Cross-Encoder Rerank 精排，提升相关性 |
| 21 | GraphRAG 和普通 RAG 区别？ | ⭐⭐⭐ | 建知识图谱做实体关系推理；适合多跳、跨文档关联 |
| 22 | Agentic RAG 是什么？ | ⭐⭐⭐ | Agent 自主决定要不要检索、检索几次、查哪些库 |
| 23 | 多模态 RAG（图文）要点？ | ⭐⭐⭐ | 图片 OCR/CLIP Embedding；iOS 端可先压缩再上传 |
| 24 | 知识库如何更新？ | ⭐⭐⭐ | 增量索引、版本号、删除向量、灰度发布 |
| 25 | RAG 怎么评估？RAGAS 指标？ | ⭐⭐⭐⭐ | Faithfulness、Answer Relevance、Context Precision/Recall；Golden Set + 人工/LLM Judge |
| 26 | 长文档怎么处理？ | ⭐⭐⭐ | Map-Reduce 摘要、父子 Chunk、滑动窗口 |
| 27 | 引用溯源（Citation）怎么做？ | ⭐⭐⭐ | Prompt 要求标注 chunk id；UI 展示原文跳转 |
| 28 | 向量维度、距离度量（Cosine/L2）？ | ⭐⭐⭐ | Cosine 常用文本语义；归一化后 Cosine≈点积 |
| 29 | 私有化部署 RAG 架构？ | ⭐⭐⭐ | 内网 LLM + 本地向量库 + 网关鉴权 |
| 30 | iOS 客户端在 RAG 链路中的位置？ | ⭐⭐⭐⭐ | 通常只做 **Query 提交 + 流式展示**；检索在服务端；注意缓存、离线提示、敏感词 |

## 三、Agent（智能体 · 16 题）

| # | 题目 | 频率 | 要点 |
|---|------|------|------|
| 31 | LLM 和 Agent 区别？ | ⭐⭐⭐⭐⭐ | LLM 只生成文本；Agent = LLM + **规划 + 工具 + 记忆 + 循环** |
| 32 | Agent 和 Workflow 区别？ | ⭐⭐⭐⭐⭐ | Workflow 路径固定；Agent 根据 Observation **动态**选下一步 |
| 33 | ReAct 是什么？ | ⭐⭐⭐⭐⭐ | Reason + Act 循环：Thought → Action（调工具）→ Observation → 直到 Finish |
| 34 | Agent Loop / Planning 模式有哪些？ | ⭐⭐⭐⭐ | ReAct、Plan-and-Execute、Reflection、Multi-Agent 分工 |
| 35 | Agent Memory 怎么设计？ | ⭐⭐⭐⭐⭐ | 短期：对话 Buffer / 滑动窗口；长期：向量库存摘要或事实 |
| 36 | Multi-Agent 协作模式？ | ⭐⭐⭐ | 主管分发、流水线、辩论；注意成本与延迟 |
| 37 | Agent 任务怎么拆？ | ⭐⭐⭐⭐ | 意图识别 → 子目标 → 工具选择 → 结果汇总；失败重试与兜底 |
| 38 | Agent 安全：Prompt 注入怎么防？ | ⭐⭐⭐⭐⭐ | 系统提示隔离、工具白名单、输入过滤、输出审核、最小权限 |
| 39 | Agent 成本怎么控？ | ⭐⭐⭐⭐ | 模型分级、缓存、限制 Loop 次数、小模型做路由 |
| 40 | LangChain / LangGraph 了解吗？ | ⭐⭐⭐ | 编排框架；Graph 显式状态机，适合复杂 Agent |
| 41 | 设计一个客服 Agent（开放题） | ⭐⭐⭐⭐⭐ | 意图分类 → FAQ/RAG → 工单工具 → 人工转接 → 评测 |
| 42 | Agent 超时 / 死循环怎么处理？ | ⭐⭐⭐⭐ | max_steps、单步超时、重复检测、降级回复 |
| 43 | Human-in-the-loop 什么时候需要？ | ⭐⭐⭐ | 支付、删数据、医疗法律等高风险操作前确认 |
| 44 | MCP 和 Agent 关系？ | ⭐⭐⭐⭐ | MCP 提供**标准化工具接入**；Agent 通过 MCP Client 调 Server |
| 45 | iOS App 里的「Agent 感」功能怎么实现？ | ⭐⭐⭐⭐ | 后端 Agent 编排；客户端 **SSE 流式 + 工具结果卡片** + 加载态/取消 |
| 46 | Siri / 快捷指令 / App Intents 和 Agent 对比？ | ⭐⭐⭐ | 系统级意图+本地工具；LLM Agent 更灵活但需云端 |

## 四、工具调用 · MCP · 协议（12 题）

| # | 题目 | 频率 | 要点 |
|---|------|------|------|
| 47 | Function Calling 是什么？底层怎么实现？ | ⭐⭐⭐⭐⭐ | 模型输出结构化 tool name + args；**运行时**由应用执行函数；不是模型真调 API |
| 48 | MCP（Model Context Protocol）是什么？ | ⭐⭐⭐⭐⭐ | Anthropic 推的 **工具/上下文** 开放协议；Client-Server；解决 N 模型 × M 工具对接 |
| 49 | Function Calling vs MCP 区别？ | ⭐⭐⭐⭐⭐ | FC 是模型侧能力；MCP 是**生态标准**（发现工具、鉴权、传输） |
| 50 | A2A（Agent-to-Agent）协议？ | ⭐⭐⭐ | Agent 间协作标准；与 MCP（Agent-Tool）互补 |
| 51 | Skills 是什么？和 Prompt 区别？ | ⭐⭐⭐ | 可复用领域能力包（指令+工具+示例）；比裸 Prompt 更可维护 |
| 52 | 工具描述（Schema）怎么写才好？ | ⭐⭐⭐⭐ | 清晰 name/description、参数类型与 enum、示例；影响模型选对工具 |
| 53 | 工具调用失败怎么兜底？ | ⭐⭐⭐⭐ | 重试、换工具、告知用户、降级静态答案 |
| 54 | MCP Server 安全治理？ | ⭐⭐⭐ | OAuth、权限范围、审计日志、沙箱 |
| 55 | iOS 能否直接跑 MCP Server？ | ⭐⭐⭐ | 一般 **客户端不跑**；移动端通过自家 BFF 调云端 MCP/工具 |
| 56 | REST API vs Tool Calling 封装差异？ | ⭐⭐⭐ | Tool 需 JSON Schema；参数由 LLM 填；要做校验与防注入 |
| 57 | 并行 Tool Call 怎么处理？ | ⭐⭐⭐ | 模型一次返回多个 call；async 并行执行再汇总 Observation |
| 58 | OpenAI / Claude / Gemini 工具调用差异？ | ⭐⭐⭐ | 字段名、流式 tool delta、strict mode；网关层做适配 |

## 九、面试回答技巧

1. **先架构后细节**：RAG 题先讲链路，再讲 Chunk/Rerank 优化。  
2. **结合项目**：准备 1 个「App 接 AI」故事：流式 UI、错误处理、成本控制。  
3. **承认边界**：客户端不负责训练；强调 **安全、体验、与服务端协作**。  
4. **2026 关键词**：MCP、Agentic RAG、Context Engineering、LLM Gateway、Evals。
