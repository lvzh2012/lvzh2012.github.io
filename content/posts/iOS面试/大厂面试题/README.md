## 各厂面试特点（选题策略）

| 公司 | 一面 | 二面 | 三面 |
|------|------|------|------|
| **字节** | 基础+网络+算法 | 系统设计+LLVM | 网络底层+架构+算法 |
| **阿里** | Runtime/KVO/Block | 内存+线程+持久化 | 项目+架构+场景 |
| **腾讯** | 项目+网络协议 | 基础+算法×2 | 项目+算法 |
| **美团** | 项目+多线程+HTTP | OC基础+MVVM+单测 | 资源管理+排序算法 |
| **百度** | 基础+跨平台 | Runtime 深入 | 底层+架构+算法 |
| **网易** | OC底层+响应链+HTTPS | 基础+算法 | 项目 |

## 使用建议

1. 先过本地 **OC/Swift 1～5 章 + Common 6～10 章**
2. 按目标公司刷对应真题文件
3. 用 [06-高频考点TOP50](/posts/%E9%AB%98%E9%A2%91%E8%80%83%E7%82%B9-top-50%E8%B7%A8%E5%85%AC%E5%8F%B8%E7%BB%9F%E8%AE%A1.html) 查漏补缺  
4. 投 AI 相关业务岗，加刷 [08-AI与大模型](/posts/ai-/-%E5%A4%A7%E6%A8%A1%E5%9E%8B%E9%9D%A2%E8%AF%95%E9%A2%9820252026-%E7%83%AD%E9%97%A8.html)  
5. 每题准备 **30 秒版 + 3 分钟版** 答案，结合自己的项目

## 算法附录（大厂常考）

| 题型 | 代表题 | 出现公司 |
|------|--------|----------|
| 链表 | 反转、合并有序链表、找环入口 | 字节、网易、腾讯 |
| 二叉树 | 最近公共祖先 LCA | 字节一面 |
| 排序 | 快排/堆排复杂度、TopK | 阿里三面、美团三面 |
| 哈希 | 两数之和、LRU 缓存 | 百度、字节 |
| 字符串 | 最长无重复子串 | 多家 |

**阿里二面场景题**：1G 内存对 1T URL 文件去重 → Bitmap / 外部排序 / 布隆过滤器（客户端岗也可能考）。
